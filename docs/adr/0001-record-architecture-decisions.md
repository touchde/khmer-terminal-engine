# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-09

## Context

KTE will need upstream maintainers in many projects to trust its decisions. Reasoning that only lives in chat or in commit messages is hard to cite.

## Decision

Record significant decisions as short Markdown ADRs in `docs/adr/`.

## Consequences

Upstream PRs can link to the reasoning behind a choice. Reversing a decision means writing a new ADR that supersedes the old one.
