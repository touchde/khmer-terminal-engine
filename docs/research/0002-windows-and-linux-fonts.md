# Research 0002: Windows and Linux fonts

- **Date:** 2026-11-09
- **Phase:** 0 (width spec)
- **Tool:** [`tools/kte-measure`](../../tools/kte-measure/src/main.rs), run by the [`Measure fonts`](../../.github/workflows/measure.yml) workflow (run 42596789754)
- **Question:** Does the [KTE Width Spec 0.1.0](../../spec/kte-width-spec.md) table, derived from macOS-installed fonts in [Research 0001](0001-khmer-advance-measurements.md), also fit the Khmer fonts that ship with Linux and Windows?

## Method

Same as Research 0001, run on GitHub's `ubuntu-latest` and `windows-latest` machines:

- **Linux:** the Debian/Ubuntu packages `fonts-khmeros` (Khmer OS family) and `fonts-noto-core` (Noto Sans Khmer, Noto Serif Khmer). 16 Unicode Khmer fonts.
- **Windows:** every font in `C:\Windows\Fonts`. Only the **Leelawadee UI** family (3 faces) covers Khmer. **Khmer UI**, Windows' dedicated Khmer font, is not installed on these machines.

New in this run: rule **S** scores the published spec table as-is, and a table lists codepoints where the measured fonts disagree with it.

## Results

| Platform | Fonts | Spec fit (±20%), all | Spec fit, common fonts | Squeezed | Gap | Codepoints disagreeing |
|---|---|---|---|---|---|---|
| macOS (Research 0001) | 160 | 96% | 100% | 3% | 0% | 0 |
| **Linux** | 16 | **98%** | **100%** | 2% | 0% | 0 |
| **Windows** (Leelawadee UI) | 3 | **86%** | **80%** | 0% | 14–20% | 13 |

### Where Leelawadee UI disagrees

Leelawadee UI draws the wide consonants at standard width:

| Codepoint | Leelawadee UI | Spec |
|---|---|---|
| ឃ ញ ឍ យ ល ស ហ ឡ ឦ | 2 | 3 |
| ឈ ណ | 3 | 4 |
| ឲ | 1 | 2 |
| ◌្ឞ (subscript) | 0 | 1 |

## Interpretation

- **Linux defaults agree completely** with the spec.
- **Leelawadee UI is the outlier.** It narrows the wide letters. Under the spec, those syllables get slightly more space than they need (a small gap), never less (no overlap). Text stays readable and aligned, but spacing is less even than with other fonts.
- Changing the spec to match Leelawadee UI would break the fit for the other 176 fonts, so the spec table stays as it is.
- **Recommendation for KTE terminals on Windows:** bundle or prefer Noto Sans Khmer or Khmer OS, and use Leelawadee UI only as a fallback.

## Limitations

- **Khmer UI** (the main Windows Khmer font) is still unmeasured. A Windows machine with the Khmer supplemental fonts installed is needed.
- Same sample text as Research 0001 (188 syllables, not yet reviewed by native readers).

## Reproduce

```sh
gh workflow run measure.yml   # then download the artifacts from the run
```
