# kte-capi

C ABI for embedding KTE in native terminals (C, C++, Swift, Zig).

C ABI over `kte-core`, for native terminals and WebAssembly hosts. Header: [`include/kte.h`](../../include/kte.h). Example: [`examples/c/demo.c`](../../examples/c/demo.c).

Part of [Khmer Terminal Engine](../../README.md).
