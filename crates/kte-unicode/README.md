# kte-unicode

Khmer Unicode classification, syllable segmentation, and the KTE cell-width rule.

Implements the [KTE Width Spec](../../spec/kte-width-spec.md): character classes, cluster segmentation (UAX #29 + coeng joining), and cluster widths in half-units for the Wide and Compact cell models. Checked against the shared corpus.

Part of [Khmer Terminal Engine](../../README.md).
