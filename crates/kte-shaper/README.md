# kte-shaper

Khmer text shaping (HarfBuzz) and shaped-cluster metrics for terminal grids.

Shapes Khmer runs with [`harfrust`](https://github.com/harfbuzz/harfrust) (the HarfBuzz project's Rust port), groups glyphs into KTE clusters, and computes the font size at which a consonant spans its cells.

Part of [Khmer Terminal Engine](../../README.md).
