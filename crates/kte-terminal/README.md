# kte-terminal

Terminal model: VT/ANSI parsing, grid, cursor, selection, and wrapping with Khmer-aware clusters.

A terminal model: VT/ANSI parsing (via `vte`), grid with multi-cell clusters, cursor, autowrap, scroll regions, scrollback, alternate screen, SGR attributes, selection that returns the original codepoints, and replies to cursor-position and mode-2027 queries.

Part of [Khmer Terminal Engine](../../README.md).
