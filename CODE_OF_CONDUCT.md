# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

## In short

We want a welcoming, harassment-free community for everyone, whatever their age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, colour, religion, or sexual identity and orientation.

Expected behaviour:

- Be respectful and kind, including to people still learning Khmer or still learning terminal internals.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the community and the language.

Unacceptable behaviour includes harassment, insults, personal or political attacks, publishing others' private information, and any conduct that would be inappropriate in a professional setting.

## Enforcement

Report incidents privately to the project maintainers through the contact listed on the maintainer's GitHub profile, or by opening a private security advisory if no other channel is available. All reports will be reviewed promptly and kept confidential.

Maintainers follow the [Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): correction, warning, temporary ban, permanent ban.
